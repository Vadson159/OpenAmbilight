# OpenAmbilight

[English](README.md) | **Русский**

Синхронизация RGB-подсветки ПК с цветами экрана через OpenRGB.

![OpenAmbilight Preview](https://i.imgur.com/DGwdrtX.png)

## Что умеет программа
Захватывает доминирующий цвет с монитора и отправляет его на все RGB-устройства через OpenRGB. Поддерживаются оперативная память, вентиляторы, светодиодные ленты, подсветка материнской платы, периферия и любые другие устройства, работающие с OpenRGB.

## Два способа запуска

1. **Внутри OpenRGB в виде плагина** (`plugin/`, основной вариант на этом ПК). Нативный C++ порт Python-приложения, загружаемый пропатченным OpenRGB из `OpenRGB-patched/`: вкладка **Ambilight** в окне OpenRGB, пункт Ambilight в меню трея OpenRGB, горячая клавиша `Ctrl+Alt+A` и запуск вместе с OpenRGB при входе в систему. Без Python и без SDK-подключения — около 0,4% одного ядра CPU на OpenRGB и Ambilight вместе.
   Сборка, установка и тесты: [plugin/README.md](plugin/README.md). Плагин должен собираться тем же компилятором и с теми же заголовками, что и сам OpenRGB.
2. **Автономное Python-приложение** (`Ambilight.pyw`), работающее с любым OpenRGB через SDK Server — описано ниже. Если рядом установлен плагин, двойной клик по `Ambilight.pyw` предложит открыть OpenRGB (чтобы два экземпляра не управляли подсветкой одновременно); флаг `--legacy` принудительно открывает старое окно.

## Языки интерфейса
И нативный плагин OpenRGB, и автономное приложение (`Ambilight.pyw`) поддерживают **английский** и **русский** языки:
* В правом верхнем углу интерфейса доступен переключатель **Язык / Language**: **Авто**, **English** и **Русский** (применяется сразу, без перезапуска).
* В режиме **Авто** плагин автоматически следует за языком OpenRGB (и обновляется на лету при смене языка в настройках OpenRGB), а `Ambilight.pyw` — за языком интерфейса Windows.
* В консольном режиме (CLI) язык можно задать флагом `--lang ru`, `--lang en` или `--lang auto`.

## Синхронизация устройств

Автономное приложение собрано в один файл `Ambilight.pyw`. Опция **Синхронизировать устройства** включена по умолчанию: все устройства получают одни и те же кадры с компенсацией измеренных аппаратных задержек. Общая частота обновления следует за самым медленным устройством (около 3,6 FPS на этом ПК) независимо от FPS захвата экрана. Отдельные ARGB-разъёмы MSI записываются последовательно, остальные устройства выравниваются между ними. Флаг `python Ambilight.pyw --cli --no-sync` возвращает независимое обновление устройств.

Замеры, аппаратные ограничения и методика проверки: [отчёт о синхронизации](diagnostics/sync-2026-10-23/REPORT.md).

## Требования
* **ОС**: Windows 10/11
* **Python**: 3.10+ ([python.org](https://www.python.org/))
* **OpenRGB**: ([openrgb.org](https://openrgb.org/))

## Установка (3 минуты)
1. Установите Python с [python.org](https://www.python.org/).
2. Запустите `install.bat` (скрипт автоматически установит все зависимости Python).
3. Запустите OpenRGB от имени **администратора**:
   * Убедитесь, что все ваши устройства обнаружены.
   * Перейдите на вкладку **SDK Server** и нажмите **Start Server**.
4. Проверьте список устройств:
   ```bash
   python Ambilight.pyw --list
   ```
   В консоли должны отобразиться ваши устройства.
5. Проверьте смену цветов:
   ```bash
   python Ambilight.pyw --test
   ```
   Подсветка на устройствах должна перебирать тестовые цвета.
6. Запустите Ambilight:
   Откройте `Ambilight.pyw` двойным кликом для запуска GUI или используйте консольный режим:
   ```bash
   python Ambilight.pyw --cli
   ```

## Использование
```bash
Ambilight.pyw                        # открыть GUI (или двойной клик)
python Ambilight.pyw --cli           # консольный режим (по умолчанию 60 FPS)
python Ambilight.pyw --fps 30        # задать частоту захвата экрана
python Ambilight.pyw --monitor 2     # выбрать конкретный монитор
python Ambilight.pyw --width 1920    # подсказка ширины монитора
python Ambilight.pyw --brightness 70 # ограничить яркость на 70%
python Ambilight.pyw --no-sync       # независимое обновление устройств
python Ambilight.pyw --lang ru       # язык интерфейса (auto, en, ru)
python Ambilight.pyw --test          # тест цветов
python Ambilight.pyw --list          # список устройств
python Ambilight.pyw --restore       # сбросить устройства в режим по умолчанию
```
Для остановки в консоли нажмите `Ctrl+C`.

## Горячая клавиша (опционально)
И плагин OpenRGB, и Python-окно сами регистрируют глобальное сочетание `Ctrl+Alt+A` (настраивается). Для старого консольного варианта есть скрипт `ambilight_hotkey.ahk` (требует [AutoHotkey v2](https://www.autohotkey.com/)) — не запускайте его одновременно с плагином или GUI:
* `Ctrl+Alt+A`: включить/выключить Ambilight

## Решение проблем
* **«SDK-сервер OpenRGB недоступен» / "Could not connect to OpenRGB SDK Server"**
  * Убедитесь, что OpenRGB запущен.
  * Убедитесь, что в OpenRGB запущен **SDK Server**.
* **«Горят не все вентиляторы»**
  * Для ARGB-разъёмов материнской платы по умолчанию задано 0 светодиодов.
  * Откройте OpenRGB, выберите нужный разъём (например, `JRAINBOW`) и укажите точное количество подключённых светодиодов в настройках зоны.

## Как это работает
Скрипт захватывает экран через Windows Desktop Duplication API и уменьшает каждый кадр на GPU, поэтому до CPU доходит только крошечная миниатюра, а нагрузка на процессор близка к 0%. Далее с помощью `numpy` вычисляется наиболее выразительный доминирующий цвет, выполняется плавный переход, и команды отправляются по локальному TCP-соединению в OpenRGB SDK Server.

Плагин делает то же самое на C++ прямо внутри процесса OpenRGB и передаёт цвета напрямую в объекты устройств OpenRGB; математика анализа цвета побитово сверяется с Python-версией (`plugin/tests/compare_colormath.py`).
